Kino-Freikarten

Eigene Seite einrichten

Trag deinen Freikarten-Code ein. Du bekommst einen eigenen Link mit eigenem Zähler, der sich jeden Monat zurücksetzt.

Dein Code wird nicht auf dem Server gespeichert. Er steht nur in deinem eigenen Link, und dieser Teil der Adresse wird technisch nie an den Server gesendet. Gespeichert wird ausschließlich, wie viele Karten du diesen Monat eingelöst hast.

Speichere den Link. Wer ihn hat, sieht deinen Code.
