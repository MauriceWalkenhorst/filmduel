Kino-Freikarten

Eigene Seite erstellen

Zählt deine Freikarten mit und beginnt am Monatsanfang von selbst wieder bei null.

Zum Datenschutz: Dein Code wird nicht auf dem Server gespeichert. Er steht nur in deinem eigenen Link, und dieser Teil der Adresse wird von Browsern technisch nie mitgesendet.

Gespeichert werden die eingelösten Karten, ihr Datum und die Notizen, die du dazuschreibst. Nur so lassen sie sich zwischen deinen Geräten abgleichen. Schreib dort also nichts hinein, was niemand sonst lesen soll.

Bewahre den Link gut auf, denn wer ihn hat, sieht deinen Code und deine Notizen. Mit einer Person geteilt, zählt ihr gemeinsam.
